# 02 · 精度预算与正确性边界

> 核心问题：**流水线里哪一步可以降精度、降到哪、靠什么兜底。**
> 全部结论都有实测支撑；数字来源见各表脚注。

---

## 1. 一张表说清"每一步用什么精度"

| 环节 | 精度 | 理由 | 反例（如果不这么做） |
|---|---|---|---|
| 因子存储 Ax（L/U） | **fp32** | 内存/带宽减半，这是全部收益的来源 | — |
| 主元比较（部分主元） | **fp64**（读 fp32 值提升） | 保持分解稳定性 | 纯 fp32 主元 → OTA 误差 **9.6e2** |
| 分解中的工作向量 x | fp64（fp32 变体中取 float 以对齐 CPU 参考） | 控制累积误差 | — |
| 三角求解累加 | **fp64** | 结果精度直接进 S₁ 判据 | — |
| GMRES-IR 残差 | **fp64**（A、b、r 全 double） | 残差精度 = IR 收敛上限 | 残差若用 fp32，精化到 1e-6 就停住 |
| IR 内层 SpMV 的值 | **fp32**（仅限存储误差小的矩阵） | 字节减半换带宽 | sky130 类存储误差 1e-4 → IR 卡死 |
| 解输出 | fp64 | 判据口径 | — |

## 2. 收益链：内存 → 带宽 → 时间

### 2.1 因子内存（最确定的收益）

| 矩阵 | n | fp32 因子 | fp64 因子 | 比值 |
|---|---|---|---|---|
| bandgap | 113 | 0.013 MB | 0.016 MB | 1.23× |
| flash-adc | 989 | 0.104 MB | 0.221 MB | **2.13×** |
| pg2k | 4,050 | 2.748 MB | 4.122 MB | 1.50×* |
| pg5k | 5,000 | 3.70 MB | 5.54 MB | 1.50×* |
| pg100k | 100,352 | 83.0 MB | 166.1 MB | **2.00×** |

\* 含索引的 12B→8B/nnz 口径；**仅因子值**口径为 2.00×（pg100k 逐位复现）。
小矩阵索引占比高，因此比值偏离 2。

### 2.2 时间（拿不到理论 2×）

| 阶段 | 实测加速 | 为什么不是 2× |
|---|---|---|
| 数值分解（ST） | 1.29–1.34× | 不是纯带宽受限：gather/scatter 更新 + 依赖链（level 结构）限制了流水 |
| 三角求解（ST） | 1.30× | 带宽受限，但小规模下启动延迟占比高；n≥10k 才接近 2× |
| SpMV（大矩阵） | 1.35–2.81× | 典型带宽受限，最接近理论值 |

**判据**：算术强度 AI ≈ 0.2 FLOP/Byte（远低于 GPU 平衡点 15–60）→ 带宽受限 →
精度降半 = 字节减半 = 吞吐 ×2。凡实测偏离 2× 的，都是被**延迟/依赖**截胡。

## 3. 精度预算模型

残差满足（Carson–Higham 框架）：

```
‖x̂ − x‖ / ‖x‖  ≲  κ(A) · u_f   +   (IR 修正项)
                 └─ fp32 因子引入 ─┘   └─ 由 fp64 残差迭代压缩 ┘
```

- `u_f` = fp32 单位舍入 6e-8；`κ(A)` 可达 1e15。
- **直接解（无 IR）**：误差 ~ κ·6e-8 —— 良态（κ≤1e7）勉强，病态彻底崩。
  实测三例，同一条路径跨 12 个数量级：

  | 矩阵 | fp32 因子 + fp32 三角求解直接解 | 现象 |
  |---|---|---|
  | bandgap（n=113） | 8.4e-4 | 差但可用 |
  | flash-adc（n=989） | **2.4e9** | fp32 分解非零元从 18427 掉到 13038（丢 29%）→ 结构性退化 |
  | OTA-5T | **9.6e2** | 主元塌缩 |

- **加 fp64 残差 IR**：每轮把误差压缩到 `‖r‖/‖b‖ × κ` 的量级，实测 2–3 轮即到 1e-11。

**所以预算表的核心不是"因子能不能用 fp32"，而是"这个矩阵的 IR 会不会收敛"。**
IR 收敛的实测经验边界：

| 条件 | 结论 | 证据 |
|---|---|---|
| κ_ruiz ≤ 6.5e11 | fp32 因子 + IR 可收敛 | 33 矩阵扫描 |
| κ_ruiz > 6.5e11 | 需 fp64 因子或增强预处理 | flash-adc（κ 4.6e12） |
| 静态 κ 与结果无单调关系 | **不能查表，必须试跑** | rajat22 κ2.8e15 成功 / OTA κ1.5e13 失败 |

## 4. 正确性护栏（三道）

1. **主元护栏**：分解时若 `min|pivot| < 1e-9 · max|A|`，判定因子不可靠 → 直接换 fp64 因子。
2. **残差护栏**：GMRES-IR 的残差始终 fp64 计算，收敛判据 `‖r‖/‖b‖ ≤ rtol`（典型 1e-10）。
3. **失败升级**：fp32 路径失败（分解报奇异 / IR 不收敛 / 残差超限）→ 按 `04_adaptive_policy.md`
   升级到 P-safe（fp64 + Ruiz + shift）或 P-hard。

## 5. fp16 的边界（为什么没成为主路径）

| 测量 | 结果 |
|---|---|
| SpMV 用 fp16 值存储 + fp32/fp64 累加的输出误差 | ~1e-4（bandgap / pg5k / OTA），rajat10 = **0.0** |
| 值域检查 | 33 矩阵中 **32 个**有 4–33% 的值 < fp16 最小正常数 6e-5 |
| 结论 | 原始值 **不能直接存 fp16**；必须先 Ruiz 均衡把值域压进 [6e-5, 65504] |

`1e-4` 的扰动作为 **IR 预条件**可接受（IR 会修正），作为**直接求解**则误差 ~κ·1e-4，不可接受。
实际只有 rajat10 这类"全值同量级"的矩阵天然满足。
