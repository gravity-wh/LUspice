# 03 · GMRES-IR：让 fp32 因子"够用"的那层壳

> 一句话：**因子存 fp32，但每次修正都用 fp64 算残差**，把因子精度损失迭代压回去。
> 没有这层壳，fp32 因子只能做 fp32 精度的解；有了它，fp32 因子能给出 fp64 精度的解。

---

## 1. 算法结构

```
输入：A（fp64）、b、静态因子（L/U 存 fp32、P/Q 置换）
1. x₀ = trisolve(L, U, P, Q, b)          # 初始解，fp32 因子（优化 2 的产物）
2. r = b − A x₀                          # ★ fp64 残差（SpMV，全 double）
3. 循环（外层 outer）:
     z = GMRES(A, r, M⁻¹ = 静态因子, inner, rtol)   # 内层迭代，预条件求解
     x += z
     r = b − A x
     若 ‖r‖/‖b‖ ≤ rtol → 退出
4. 输出 x（fp64）
```

关键点：**内层 GMRES 用 fp32 因子做预条件，但矩阵向量乘 A·v 与残差始终 fp64。**
这是 Carson–Higham 的 GMRES-IR 变体——预条件子可以低精度，只要迭代矩阵的谱性质够好，
误差会被外层修正吸收。

## 2. 参数取值与演化（重要：这里改过结论）

参数不是一次定下来的，中间翻过一次案。**最终定稿如下，早期"增强 IR"的说法已作废。**

| 参数 | 最终值 | 依据 |
|---|---|---|
| `max_outer`（外层 IR 轮数） | **1 ~ 3** | 增强到 7 轮反而在 flash-adc 上重新 NaN |
| 内层 GMRES `m` | 50 | 再大收益饱和，内存换不来精度 |
| 内层 `maxiter` | 300 | — |
| `rtol` | **1e-9 ~ 1e-10** | 1e-10 更稳但多 1 轮；实测良态矩阵两种都到 1e-11 级 |
| `shift` | **1e-7 · |diag|**（默认开启） | flash-adc 从 NaN → 1.7e-10 的唯一开关 |
| Ruiz | **按需**，见下 | — |

### 2.1 被推翻的结论（避免重走）

> 早期判断"增强 IR（outer=7 / inner=100 / maxiter=600）是关键"——**完整扫描后证伪**。
> 增强 IR 在 flash-adc 上**重新出现 NaN**，只有 `outer ≤ 3` 才稳定。

### 2.2 移位因子：唯一真正有效的开关

`shift = 1e-7·|diag|` **只作用于因子分解**（构造 L/U 时把对角加上一个小量），
matvec 仍用**原矩阵**。效果：

| 矩阵 | 无移位 | 有移位 |
|---|---|---|
| flash-adc | NaN | **1.7e-10** |
| limiting-amplifier | 失败 | 1.2e-10 |
| sc-dac-6bit | 失败 | 3.5e-12 |

对三个病态矩阵有 10–40× 的残差改善。这个开关在 `fpgmres.c` 里早有 `use_shift` 选项但默认关闭，
GPU 内核必须**默认开启**。

### 2.3 Ruiz 什么时候用、什么时候别用

判据是**先算 Ruiz 缩放能带来多少降幅**，不是看 κ：

| Ruiz 降幅 | 类型 | 处理 |
|---|---|---|
| > 1e2 | 行列尺度失衡型（如 s0_tb1_ff9，降 1.26e5×） | **用 Ruiz** |
| < 1e2 | 固有近奇异型（neural / sc-dac） | **跳过 Ruiz**，裸 fp32 反而收敛 |

## 3. 实测收敛表现

### 3.1 良态矩阵（fp32 因子 + IR）

| 矩阵 | n | 内迭代数 | 最终相对残差 |
|---|---|---|---|
| bandgap | 113 | 3 | 8.49e-12 |
| pg2k | 4,050 | 2 | 7.63e-11 |
| pg5k | 5,000 | — | 6.6e-15 |
| pg100k | 100,352 | — | 7.1e-10 |
| rajat22 | 39,899 | — | 3.2e-10 |

### 3.2 病态矩阵（需 P-safe / P-hard）

| 矩阵 | κ | 路径 | 残差 |
|---|---|---|---|
| sky130-capacitive-neural-amplifier | — | fp64 + Ruiz 结构对齐 | 5e-16（CPU 参考）；GPU 结构对齐 347/363 |
| sky130-flash-adc-3bit | 4.6e12 | fp64 + shift 1e-7 | 1.7e-10 |
| sky130-segmented-current-steering-dac | — | fp64 + bare | 3.5e-12 |

### 3.3 已知数值缺口

病态矩阵上 **GPU 三角求解精度 1.9e-4，而 CPU 参考 5e-16**。
根因是 FMA 使用与累加顺序差异（同一算法、不同指令序列），不是算法错误。
这是当前 GPU 路径最主要的未解项——对应 `04_adaptive_policy.md` 的 P-hard 想解决的问题。

## 4. 符号复用：IR 迭代的成本摊薄

IR 每轮要 1 次三角求解 + 1 次 SpMV，但**符号分解、重排序只做一次**：

- 稳态 Newton 迭代中矩阵模式恒定（实测 nnz 恒定 9042）→ 符号分解 1 次，数值分解每步复用；
- 实测：两次 numeric 仅 1 次 symbolic（计数器 `dsh_symbolic_count()` = 1）；
- 模式变化检测：nnz 或列结构变化才重做符号分解。

---

## 5. 与 SpMV 格式的配合

| 矩阵类型 | SpMV 格式 | 实测带宽 |
|---|---|---|
| 行均匀（pg 系，n≥10k） | **SELL-C-σ32** | 78.3% 峰值 |
| 长尾（rajat 系） | CSR | 比 SELL 好 43% |
| 小矩阵（n<10k） | CSR | 启动开销主导 |

格式选择由 `src/selector.c` 决定，选择器与精度路径解耦——先定格式，再定精度。
